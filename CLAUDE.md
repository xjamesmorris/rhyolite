# Claude contributor guidance

Read and follow [AGENTS.md](AGENTS.md), the canonical repository development
contract. This file is a contributor bootstrap pointer only; it does not
define separate policy.

Rhyolite's production runtime harnesses are GitHub Copilot CLI, Claude Code,
and OpenAI Codex CLI. [README.md](README.md) documents how to run Rhyolite
through Claude Code with `rhyolite --harness claude` and through OpenAI Codex
CLI with `rhyolite --harness codex`; this pointer does not change that runtime
behavior.
